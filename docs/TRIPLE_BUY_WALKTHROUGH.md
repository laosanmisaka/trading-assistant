# 当前三买策略合同：observable-v1

本版本以 [core/causal_signals.py](../core/causal_signals.py) 为事件源，替代用完整历史的笔端点倒填成交时刻。研究入口为 [eval_daily_5min.py](../scripts/eval_daily_5min.py)，图表入口为 [core/triple_buy.py](../core/triple_buy.py)，监控入口为 [monitor_buy.py](../scripts/monitor_buy.py)。

## 窗口与入场

逐根推进日线 czsc。当前末笔被自研几何判为三买、前一笔向上、突破幅度小于 40%、突破终点不超过 90 自然日时，窗口首次出现。`available_at` 是实际观察到该结构的日线收盘时刻，不是突破笔的历史终点。

窗口失效、超龄或被后续笔确认时关闭；消失后再出现会形成新的开放区间。事件回放包含后来失败的候选，不只保留最终成功三买。

5min 逐根推进；一买的下一根笔必须在当前结构中真实存在，才算观察到确认。一买本身仍是自研纯几何规则（参照中枢、低点与分段收敛），没有启用 MACD 背驰。已在窗口开放前观察到的旧点不能在窗口开放后倒填为新入场。

入场时刻 `conf` 为当前收口 bar 的时间，价格为该 bar 的 close。这是乐观的收盘成交模拟，未证明实盘能够以该价格成交。窗口内第一次观察到的一买消耗唯一入场资格；其后信号记录为非首次，不能因原信号后来变差而换成更好点。

## 稳定身份与修订

- 窗口身份来自突破笔时间锚和首次可用时刻。
- 点身份来自 5min 笔的起点时间；事件身份组合股票、窗口和点身份，不使用会随滚动数据重编号的 `bi_idx`。
- `conf`、`entry_dt`、`entry_price` 记录首次观察，持久化后不可被滚动回放改写。
- 几何低点、几何价格、`active`、`revision`、`updated_at` 表示后续状态。撤销保留历史入场，不继续作为有效待执行买点显示。
- 日志先按事件身份合并最新修订，再过滤资格和日期。撤销或取消资格不能留下旧版本的有效列表项。

这是算法信息时间的改进，不证明所有未来信息都已消失：行情后复权/前复权的历史修订、当前存活样本选择和源数据本身仍可能引入研究偏差。新浪滚动数据与 baostock 长历史起点不同，不再宣称“近端结构一定不受起点影响”或“1010/1010 必定相同”。

## 出场与统计

默认持有 20×48 根已收口 5min bar，固定持有，不开启已否定的动态止损/止盈策略。48 根只是完整交易日的换算：停牌、缺 bar 会延长实际日历时间。结果必须披露输入缺口和实际时间，不能把不完整数据下的 bar 数冒称严格 20 个交易所交易日。

逐点结果可重叠，不是资金曲线。每个信号收益减去其标的随机入场基准后，再求点均超额；标的等权列配套标的等权基准。cluster 和季度 block bootstrap 都估计相同的点均配对超额，只改变重抽分组。中位、极值和盈亏比由完整逐点样本计算，不平均各股的中位数。

随机基准是在该股可用历史中枚举同持有长度入场，不保证与信号日历时段匹配。当前随机池从当前上市范围抽样，仍有存活偏差；固定随机种子不能替代逐时点可投资样本。

## 可复现研究

```bash
python scripts/eval_daily_5min.py --pool scripts/pool_random500.txt --holds 20 --max-amp 40 --dump-points outputs/points.csv
```

先用相同来源、复权、区间取齐 daily/5min。报告应连同命令、代码 SHA、依赖、池及行情哈希、逐点记录保存；缺少真实行情数据的合成回放只能验证算法合同，不能认证市场收益。

`eval_triple_prob.py --retrospective` 和 `eval_triple_buy.py` 属于完整历史几何诊断。前者的 cross/confirm 均含事后结构信息，不是前瞻概率；旧 +4.06% 超额、63% 胜率、1010/1010 等数字依赖未公开 `outputs/`，本次不认证也不沿用为新算法结论。

默认离线测试直接使用真实 czsc 生成结构，核对当前窗口、确认前缀、监控/研究/图表事件一致与修订恢复。市场逐时快照及 Windows 真实通知仍需独立验收，见 [验证说明](VALIDATION.md)。
