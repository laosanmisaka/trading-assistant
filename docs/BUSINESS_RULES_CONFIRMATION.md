# 业务口径与保留事项

截至 2026-10-03，此页区分已实现行为与尚未作出的产品决策；不把旧“待确认”问题反复列为当前阻塞。

| 主题 | 当前实现与决定 |
| --- | --- |
| 当前研究/监控策略 | 日线可观察候选 + 5min 首次确认一买，幅度上限 40%，固定持有；详见策略合同 |
| 30min 与 60min | 30min 保留作历史几何诊断；自动止盈实际读取 60min，文案已统一 |
| 自动止损 | 持仓周期内日线低点只上移；不是研究策略的动态出场规则 |
| 自动止盈 | 当前成本固定倍率作为初值，后续买入日之后的 60min 顶分型可锁线；倍率不代表所有 A 股涨停制度 |
| 手动提醒 | 单项更新不覆盖另一项；手动设置跨重启保留；新持仓保留用户手动设置、重置自动状态 |
| 清仓再买 | 开启新的成本与首次买入日期周期，历史累计交易仍保留 |
| 旧买点扫描器 | 已删除，不恢复 |
| 六脉神剑 | 已删除，不恢复 |
| 做 T 框架 | 未接 GUI，资金/强平语义有未闭环问题；不作为可用产品发布 |

## 仍需产品决定

是否将止损初始化扩展到超过 120 根日线的全部持仓期，以及是否接通表格/图表的止损止盈线，仍是保留功能范围。当前文档和 GUI 不声称这些显示已完成。做 T 模块若将来重新启用，应重新明确自有仓位、虚拟资金和强平合同，再实现与验收；本轮不扩张该功能。

当前固定 20×48 根 bar 与“20 个交易所交易日”在停牌/缺行情时不同，研究输出明示 bar 口径；更换持有期定义必须作为策略版本变更，不能静默改写旧统计。

项目自有代码的授权方式尚未指定，本轮只补第三方资源来源与许可，不代替维护者作授权决定。
